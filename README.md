# 车间盘点

铝型材车间每日盘点用的 iPad 小程序。在 iPad 的 Safari 中打开网址，点“分享”→“添加到主屏幕”，之后就像 App 一样从桌面打开，没网也能用。

- 型号从型号库里选，长度和理论支重自动带出，只填支数
- 实际支重 = 理论支重 ÷ 6 × 长度；理论重量 = 实际支重 × 支数
- 状态：已入库 / 包装中 / 刚生产，“入库 ✓”一键改为已入库
- 导出 Excel（明细、按型号汇总、按状态汇总，状态带下拉和颜色）
- 数据只保存在这台 iPad 上；请定期点“备份全部数据”

文件说明：`index.html` 主程序，`catalog.js` 初始型号库，`exceljs.min.js` 生成 Excel 的组件（离线用），`sw.js` 离线缓存，`manifest.webmanifest` 和图标用于添加到主屏幕。
